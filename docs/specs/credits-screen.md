# In-game Credits screen

One read-only screen that lists everything T3 Craft builds on, grouped by kind. It has no settings, filters or search.

## Where it opens

| Entry point | How |
|---|---|
| **Mod Menu → T3 Craft → config button** | T3 Craft has no settings screen (connection is automatic), so the config button opens Credits. Register a `modmenu` entrypoint (`T3ModMenu implements ModMenuApi`) whose `getModConfigScreenFactory()` returns `parent -> new T3CreditsScreen(parent)`. Mod Menu is a `compileOnly`/`modCompileOnly` dependency and is listed under `suggests` in `fabric.mod.json`, never `depends`, so the mod still loads without it. |
| **T3 panel → ⋯ menu → "Credits"** | Last item in the overflow popover, below a 1 px `BORDER` divider: Review changes, Activity, Pin to desk, ─, Credits. It opens at once with `parent = the T3Screen`. |

Esc or the "Done" button returns to `parent`. Nothing else opens the screen, so there is no keybind and no command.

## Data

- Source: `assets/t3craft/credits.json`, generated by `credits/generate.py`. Never edit it by hand.
- Load it once on first open with `Minecraft.getInstance().getResourceManager().getResource(Identifier.fromNamespaceAndPath("t3craft", "credits.json"))` and parse it with Gson. Cache the parsed groups for the session.
- Shape:
  ```json
  {
    "format": 1,
    "project": "T3 Craft", "license": "MIT", "repo": "https://github.com/alexandros-lekkas/t3craft",
    "groups": [
      {"kind": "code", "title": "Code", "entries": [
        {"title": "T3 Craft (original project)", "author": "Maxwell Young", "license": "MIT",
         "url": "https://github.com/maxwellyoung/t3craft", "note": "The mod itself. …"}
      ]}
    ],
    "disclaimers": ["NOT AN OFFICIAL MINECRAFT PRODUCT. …", "…"]
  }
  ```
  Optional per-entry fields: `version` (mods), `original: true` (made for T3 Craft).
- If `format` isn't 1 or the file is missing, show the header, one line, "Credits are on GitHub", with the repo link, and the disclaimers. Never crash.

## Layout

The screen uses the panel redesign's tokens (`docs/design/ui.md`): Inter, the neutral ramp and the `BG_PANEL` backdrop. It has the same centred reading column as the panel, `colW = clamp(charWidth × 72, 260, contentW − 48)`.

```
┌──────────────────────────────────────────────┐
│ Credits                                    ✕ │  H1, TEXT_PRIMARY
│ T3 Craft is MIT. Built on maxwellyoung/       │  META, TEXT_SECONDARY
│ t3craft by Maxwell Young.                     │
│                                              │
│ CODE                                         │  section label, TEXT_MUTED, caps, 14 above / 4 below
│ T3 Craft (original project)          MIT  ↗ │  title TEXT_PRIMARY · license chip · link glyph
│ Maxwell Young · The mod itself. …            │  META, TEXT_SECONDARY, wraps, max 2 lines
│ Fabric Loader                 Apache 2.0  ↗ │
│ FabricMC · Mod loader T3 Craft runs on.      │
│ FONTS                                        │
│ …                                            │
│ MODPACK                                      │
│ Sodium  mc26.3-0.9.2        PolyForm Shield ↗│  version in MONO, TEXT_MUTED
│ …                                            │
│ ──────────────────────────────────────────── │
│ NOT AN OFFICIAL MINECRAFT PRODUCT. …         │  META, TEXT_MUTED, every disclaimer
│                                     [ Done ] │
└──────────────────────────────────────────────┘
```

- Group order and titles come from the JSON as written. Don't re-sort.
- Row: the title line is 12 tall and each note line is 11. Rows have 6 px between them. The license chip is right-aligned (`BG_RAISED`, 1 px `BORDER`, r 3, `META`).
- Entries with `original: true` get a small `made for T3 Craft` tag in `TEXT_MUTED` instead of the link glyph when they have no `url`.
- Hovering a row gives `BG_HOVER`. Clicking a row with a `url` goes through vanilla `ConfirmLinkScreen` (Minecraft's standard "open this link?" prompt), then opens the browser and returns here. Rows without a `url` aren't clickable.
- Scrolling uses `T3Scroll` with a thin thumb only when the list overflows. The mouse wheel and PageUp/PageDown work, and Home/End jump to the ends.
- Narration (accessibility): each row narrates "title, by author, license". Section labels narrate as headings.

## Acceptance

- It opens from both entry points, and Esc returns to the screen it came from.
- Every entry in `credits.json` is shown, and nothing is hard-coded in Java.
- With Mod Menu absent, the game loads and the ⋯ entry still works.
- The Minecraft disclaimer is always visible at the bottom of the list.
- A smoke check (`UiChecks`) opens the screen and asserts that it has the same number of groups and entries as the JSON.
