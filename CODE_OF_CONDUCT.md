# Code of Conduct

T3 Craft adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be kind and patient, and assume good intent. Harassment, discrimination, personal attacks and sharing other people's private information are not tolerated, here or in any T3 Craft space (issues, PRs, discussions, Discord, X replies on project posts).
